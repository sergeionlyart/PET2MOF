# Передача исполнителю: PET-CO2-TASK-003

В комплекте: полное поручение в Markdown и PDF, реестр первоисточников с границами проверки, контрольные суммы и скрипт проверки целостности.

**Это не новый экспериментальный DataPack.** Численные данные TASK-002 уже находятся в репозитории, в `data/task002/PET2MOF_Task002_DataPack_v1.0/`. Новые сведения по PET-derived материалам исполнитель получает из перечисленных первоисточников, проверяет и оформляет как отдельные входы TASK-003. Полные статьи и исходный архив Zenodo здесь не приложены.

## Как передать

Скачайте этот ZIP из переписки и поместите в локальную папку проекта либо приложите к сообщению исполнителю. Файлы ChatGPT не появляются автоматически на Mac и не добавляются автоматически в GitHub. Репозиторий при подготовке поручения не изменялся.

Распакуйте в отдельный каталог, не поверх прежних результатов. Внутри распакованного каталога выполните:

```sh
python3 verify_handoff.py
```

Успех проверки подтверждает целостность **этого комплекта**, а не научную достоверность источников или готовность TASK-003.

## Сообщение исполнителю

Продолжайте работу по PET-CO2-TASK-003, версия 1.0, из приложенного комплекта. Исходная точка — коммит `1558433614619e04102989d6b6f1479c50f364ce`. Создайте новую ветку `task003-pet-transfer`, не меняя историю v1 и v2. Главный результат — численно обоснованный выбор способа модификации PET-связанного MOF и границы его преимущества, а не повтор сравнения C72/C96. Сначала примите имеющиеся данные и проверьте химическую совместимость, затем выполните минимальные расчёты и независимую проверку. GitHub Actions запрещены; ключи не требуются для воспроизведения.
