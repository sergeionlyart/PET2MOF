# T019v: независимые контрольные проекты (V, не передавать разработчику до prereg-v1)

Этот каталог содержит **численные V-наблюдения**. Безопасная для передачи руководителю сводка — `reviews/T019v_holdout_verification.md`; до фиксации модели не открывать CSV/JSON с координатами и значениями.

`control.py` не импортирует скрипты извлечения T019 или модель. Контроль: регрессия по внутренним делениям осей; отдельный контраст квадратного маркера S113; аналитические цветовые трафареты S103/S102; максимумы расстояния до фона для заполненных CO2-маркеров Madden. Никакие точки не получены из сглаженной линии. Пиксели, шкалы, калибровочные деления, ошибки, хеши исходников и наложений находятся в `projects.json`. Хеши/страницы PDF и исходных изображений — `source_images.json`. Изображения и overlays хранятся только в игнорируемом `private/T019v/`.

`controls.csv` содержит контрольные центры и преобразованные координаты; `comparison.csv` — сопоставление по абсциссе в пределах четырёх пикселей, без использования q при выборе пары. `comparison_summary.json` содержит квоты и сравнение |delta| с u_dig. u_dig — стандартная неопределённость, не жёсткая граница. `control_u_dig` — оценка контрольного считывания и калибровки; общий вклад исходного изображения не делает два считывания независимыми экспериментами. Не следует интерпретировать статистику расхождений как валидацию модели.

`S2-primary-tables.json` — все строки исходных таблиц, независимо разобранные из заново загруженного JATS; `S2-comparison.csv` — соединение по имени образца и все численные проверки. PDF S2 недоступен: XML-сверка не объявлена визуальной проверкой PDF.

`blind_checkpoint.json` фиксирует завершение шагов 1–2 до чтения отчёта T019. Метаданные и CSV T019 просматривались ранее; абсолютная слепота к экспортам не заявляется. Первичные неудачные варианты сохранены с префиксом `initial_`; объяснения — `method_corrections.json`. Параметры поправлялись после сравнения с T019 только для устранения визуально подтверждённых ошибок собственного выделения/сопоставления (чужой цвет внутри полого маркера, легенда, опорная точка треугольника, смешение dry/wet при соединении). Это ограничение независимости выбора параметров явно сообщено.

Воспроизведение из корня checkout (без изменения T019):

```sh
UV_CACHE_DIR=$PWD/.uv-cache uv sync --frozen
# В текущем окружении python3 имеет PyMuPDF 1.27.2.3.
# prepare.py проверяет версию до записи: PNG-кодирование 1.28.2 даёт другие байтовые хеши.
UV_CACHE_DIR=$PWD/.uv-cache python3 data/extraction/digitization/T019v-control/prepare.py
# Если первичный XML отсутствует, к той же команде добавить --fetch-s2.
UV_CACHE_DIR=$PWD/.uv-cache .venv/bin/python data/extraction/digitization/T019v-control/control.py
UV_CACHE_DIR=$PWD/.uv-cache .venv/bin/python data/extraction/digitization/T019v-control/compare.py
```

Нужны четыре PDF с хешами `source_images.json`. Законные исходные адреса: S113 — издатель MDPI; S103 — издатель Nature; S102 — Figshare SI; Madden — Europe PMC supplementary archive. URL и идентификаторы также сохранены в паспортах T019, которые не изменяются. Для S2 `prepare.py --fetch-s2` использует только публичный Europe PMC REST и отказывается принимать изменившийся XML под старым хешем.

`protected_hashes.json` фиксирует исходные T019/holdout-файлы. `schema_checks.json` — самостоятельная проверка схемы и соединений. `passports/` — паспорта контрольных оцифровок; они provisional и не подменяют вердикты по исходным сериям. `access.json` — сохранённые ответы законных обращений (без credentials). `checks.json` — команды и результаты локальных проверок.
