# Сообщение исполнителю

Продолжите PET2MOF по новому поручению `PET_CO2_Task_002_RU.md`. Входы находятся в этом архиве и уже позволяют выполнить узкое сухое сравнение без новых API и лабораторных измерений.

Сначала выполните `make reproduce-demo`, затем подготовьте расчётную таблицу выбора двух кандидатов по основным данным S2 и оценку устойчивости выбора. Не запускайте прежний большой ансамбль. Набор S100 используется отдельно для проверки минимального алгоритма и чувствительности формы кривых; ограничения массовой основы не сняты и не должны переноситься на S2.

Сохраните результаты v1. Исправьте ненужную зависимость оператора пористости от RH и pCO₂ и проверьте именно исправленный код. В научном результате чётко различайте лабораторный контрольный материал и будущий материал из ПЭТ. Итог должен содержать конкретное инженерное решение, его границы и независимое воспроизведение, а не отчёт о количестве выполненных задач.
