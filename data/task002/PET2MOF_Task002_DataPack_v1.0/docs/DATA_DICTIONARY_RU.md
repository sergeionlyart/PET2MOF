# Словарь и договор использования данных

## S2_materials.csv — 6 образцов, ключ sample_id

`source_label` сохраняет исходное обозначение; `^C` означает предварительное насыщение PEI CO₂. BASE — исходный UiO-66-NH₂; C48/C72/C96 — химическое закрепление с предварительным насыщением; N72 — без насыщения; I96 — импрегнация без глутаральдегида.

`PEI_feed_pct_of_initial_MOF` — подача на исходный MOF; `PEI_feed_pct_of_total_feed` — подача на сумму MOF+PEI+GD. **Ни одна не является фактической долей PEI готового образца.** `PEI_content_author_calculated_wt_pct` — авторская оценка удержанного PEI по N-анализу. Не пытаться восстанавливать все её округлённые значения точно из округлённых W и N.

`mass_gain_pct_of_initial_MOF` — увеличение массы после модификации. Массовый баланс может включать GD, поэтому конечный материал не считать бинарной смесью MOF+PEI по умолчанию. BET/объём/средний размер пор описывают результаты N₂-порометрии и не тождественны доступности для CO₂ при комнатной температуре. Метаданные показывают, что происхождение из ПЭТ не установлено.

## S2_dry_CO2.csv — 6 наблюдений

`q_CO2_dry_mmol_g` — сухая насыщенная ёмкость из Table 2. `T_K=298.15` — точное арифметическое преобразование указанного 25 °C, не заявленная точность измерения 0,01 K. `pressure_lower_bar/upper_bar` обозначают две записи источника (1 bar / 1 atm), а не доверительный интервал. Температурная погрешность и повторные измерения неизвестны.

Сравнение использует сообщённые измерения при одинаковой постановке статьи. Оно не предсказывает новую изотерму по одному значению. Описанная авторами «сухость» используется только как название условий, а не как численно измеренная RH=0 с нулевой ошибкой.

## S2_secondary_properties.csv — 30 записей, ключ (sample_id, metric)

Пять типов записи на каждый образец. Значения DSC отсутствуют в трёх случаях; пустая строка — unknown, не ноль.

- `q_moist_reported`: опубликованный влажный отклик. RH и разделение массы воды не уточнены; только контекст.
- `alpha_pure_gas_capacity_ratio`: производная характеристика по отдельным газам. Не селективность реальной смеси.
- `q_total_CO2_N2_mixture`: измерено общее поглощение смеси, не только CO₂.
- `q_CO2_mixture_author_corrected`: расчёт авторов из смеси; не независимое измерение CO₂ и не точка чистогазовой изотермы.
- `Qdes_DSC`: теплота по DSC; не энергия промышленного цикла.

## S100_dry_isotherms.csv — 48 координат в 5 сериях

`q_mmol_per_g_reported` сохраняет неустановленный знаменатель «г»; нельзя переименовывать его в г сухого композита без нового источника. `sample_label` — только имя образца. `legacy_status=verified` означает принятые ранее координаты, а не верификацию всей химической постановки.

`q_digitization_halfwidth` и `p_digitization_halfwidth_bar` — консервативные границы ошибки оцифровки из v1. Они не являются экспериментальными SD. `allowed_use=benchmark_shape_only` требует использовать данные отдельно от основного решения. Одна статья и одна серия образцов не становятся независимыми при разделении соседних точек.

`S100_excluded_points.csv` хранит 2 прежние NIST-вставки, исключённые из сравнения; прежние источники и значения не удалены.

## S100_internal_split.csv

Внутренний ретроспективный тест интерполяции: 39 точек fit и 9 в блоке 0,33–0,46 bar. Все данные доступны в пакете, уже использованы в v1; никакой слепоты не заявляется. Тест проверяет восстановление неиспользованного блока той же кривой, не перенос между материалами.

## Метрики reference/

Все величины вычислены открытым скриптом. S2-интервалы: `q_low=q(1-d)-0.005`, `q_high=q(1+d)+0.005`, где d=0,03/0,05/0,10. Для сравнения A>B граница d при одинаковых независимых относительных полуширинах: `(qA-qB-0.01)/(qA+qB)`. Это детерминированный порог робастности, не статистическая вероятность. Отрицательный порог не интерпретируется как допустимая отрицательная погрешность.

`adsorbent_kg_per_kg_CO2_equilibrium_proxy=1000/(44.01*q)` — условный инвентарь для единственной равновесной загрузки. Доля 44,01 — проектная молярная масса CO₂, достаточная для данного сравнения; дополнительные цифры выходов служат воспроизводимости, а не заявленной точности.

Показатель `maximum_price_ratio...=q_i/q_base` не включает синтез, регенерацию и срок службы. Нельзя называть его LCA или технико-экономическим анализом.

## Происхождение и хеши

`metadata/legacy_sources.json` связывает неизменённые CSV с коммитом и Git blob SHA-1. `metadata/SHA256SUMS.txt` фиксирует поставленные файлы. Сам манифест, воспроизводимые журналы checks и Python-кэши не входят в его список. Отсутствующий оригинальный PDF имеет `original_file_sha256: null`, а не фиктивное значение.
