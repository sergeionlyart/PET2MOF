# PET2MOF: готовые входы для поручения 002

**Версия 1.0 • 17.11.2026.** Начните с `PET_CO2_Task_002_RU.md` (рядом PDF).

## Что решаем

Выбираем приоритетные **измеренные** сухие PEI-модифицированные образцы для следующих исследований. Не пытаемся сразу решить задачу влажного рабочего цикла на PET-derived материале.

Основной пакет: шесть образцов S2 (UiO-66-NH₂ и его модификации), шесть сухих ёмкостей и отделённые дополнительные свойства. Вспомогательный пакет: 48 прежних оцифрованных точек пяти S100-изотерм; две provisional-точки сохранены отдельно и исключены. Это **две публикации**, а не 48 независимых опытов или 30 новых испытаний.

## Запуск без ключей и установки библиотек

Требуется Python 3.10+; базовые команды используют только стандартную библиотеку. В среде подготовки проверено на Python, указанном в `checks/environment.json`.

```sh
cd PET2MOF_Task002_DataPack_v1.0
make reproduce-demo
```

Без `make`:

```sh
python3 scripts/check_data.py
python3 -m unittest discover -s tests -v
python3 scripts/reference_baseline.py
```

Сеть, `.env`, платный OCR, Claude/Codex и API не нужны для воспроизведения этих расчётов. Более сложная изотерма — будущая ограниченная работа исполнителя; SciPy для базового пакета не требуется.

## Структура

- `data/primary/`: заново перенесённые численные таблицы S2. Это главный набор решения.
- `data/benchmark/`: нормализованные координаты S100 со строго ограниченным использованием.
- `data/quarantine/`: две исключённые точки.
- `data/legacy_original/`: пять неизменённых исходных проектных CSV с проверенными Git blob SHA-1.
- `metadata/`: происхождение, разбиение, контракт и хеши.
- `reference/`: выполненные детерминированные расчёты подготовителя. Не скрытые ответы и не новая научная валидация.
- `audit_fixture/`: искусственный воспроизводитель старого программного дефекта. Он не проверяет исправленный код.
- `checks/`: фактические результаты локальных проверок.

## Что данные позволяют уже сейчас

По S2 можно сравнивать сухие измеренные ёмкости внутри статьи, считать относительный выигрыш, устойчивость к объявленным погрешностям и условный инвентарь сорбента для единственной равновесной загрузки. Например, два лучших номинальных значения близки; поставленная задача требует сохранить неразличимость, если она остаётся при анализе погрешности.

По S100 можно проверить интерполяцию и форму каждой кривой. Нельзя объявлять истинную массовую долю PEI из имени образца или рассчитывать по этим данным массу промышленного сорбента: знаменатель ёмкости не уточнён.

## Честные границы проверки

S2 сопоставлен по опубликованным таблицам в первичных HTML и текстовом представлении PDF. Визуальный рендер страниц PDF получить не удалось; его проверка не заявляется. Исходные PDF/рисунки не вложены. SHA-256 — для реально поставленных файлов; отсутствующий PDF не имеет придуманного хеша.

S100 не переоцифровывался: статус координат унаследован, файлы совпали с коммитом по Git-хешам. Эти данные уже использовались в v1. Внутренняя проверка интерполяции не является слепой внешней проверкой.

Первый полезный этап можно завершить без новых физических опытов. Полученный выбор будет относиться к указанным контрольным материалам и условиям, а не автоматически к отходам ПЭТ.
