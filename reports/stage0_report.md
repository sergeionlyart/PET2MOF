## Решение о внешнем OCR

`.env` отсутствует ⇒ бюджет 0, платный путь отключён. Пилот показал, что для используемых источников
(цифровые PDF с текстовым слоем, XML Europe PMC) локального пути достаточно: проблемы — в структуре
(связи «ячейка—заголовок», индексы), которые внешний OCR не снимает лучше визуальной разметки; числовые
данные из рисунков получаются оцифровкой, а не OCR. **Внешний OCR не требуется**; лимит не запрашивается.

## Что не подтверждено / ограничения данных

* **Целевой серии нет**: ни в одном источнике нет PEI@UiO-66 (тем более из ПЭТ) при 5 % CO2/N2, 35 °C,
  RH 0/40/70 % с раздельным учётом CO2 и H2O и известным режимом регенерации.
* Единственная серия загрузок PEI на импрегнированном UiO-66 (S100, Xian et al., IECR 2015) — при 298 K,
  чистый CO2; загрузки — **номинальные метки**, Mw PEI и активация композитов неизвестны; основной текст
  статьи закрыт (доступен SI, CC BY-NC 4.0).
* S2 (PEI@UiO-66-NH2) — отдельный контрольный материал; «влажный» опыт без численного RH.
* S3 использует коммерческие DMT/BHET, а не реальные отходы ПЭТ; CO2-данные на UiO-66 из реальных отходов
  ПЭТ есть в S115 (только аннотация доступна).
* Влажные данные: на носителе (S102 SI, Madden 2021) и на других PEI/аминных системах (S111 SI, PEI/SiO2) —
  только для проверки отдельных механизмов или чувствительности.

## Какие выводы достижимы (решение руководителя)

1. **Уровень 1 (ограничен данными):** сухая физсорбция носителя с независимой проверкой при 27–35 °C;
   сухая модель влияния PEI (M1 против B1) на S100; проверка границ переноса на S2 (D-11).
2. **Уровень 2 (условная карта состав × влажность):** по отдельным механистическим ветвям влажной химии;
   статус — **«проверяемый прогноз»**. Вердикт по H1 только при согласии всех допустимых ветвей, иначе
   «данных недостаточно» плюс минимальные различающие опыты.

Наблюдение (не вывод; оцифровка S100 Fig. S5 — `verified` после T007 и сверки с NIST, D-15): в S100 SI Fig. S5 ранжирование
композитов по сухому CO2 меняется с давлением — при ~5 кПа поглощение растёт до 40PEI, при 100 кПа 40PEI
уступает 30PEI. Это сухой прецедент зависимости ранжирования от условий (ср. H1a).

  исправлены (T008b, 55 регрессионных тестов); повторная независимая проверка T008c — в работе.
* В сохранённых страницах сайта NIST найден встроенный сторонний публичный токен карты — страницы исключены
  из Git, неотправленная история **переписана** `git filter-repo` до первого push (D-09, карта
  коммитов `docs/history_rewrite_map.txt`); `make publish-check` — 0 нарушений. В публичный репозиторий
  ничего не отправлялось, утечки не было.
* C-серия `jp308657x` (одна температура, неизвестное происхождение) заменена (D-12, D-14).
* Неоднозначность S100 Fig. S5 (температура и шкала давления) снята сопоставлением с NIST: 298 K,
  абсолютное давление, кПа (D-15). Неоднозначность определения загрузки PEI (`w = метка/100` или
  `w = r/(1+r)`) не снята — обе трактовки несутся через расчёт (D-10).
