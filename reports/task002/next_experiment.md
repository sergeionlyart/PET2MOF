# Следующий лабораторный опыт (одна страница; поручение 002 §5В)

Основание: набор А (run `20261117T044031484585Z-1acc1c2c-task002-A`, сверка
`20261117T044043117206Z-cb31d105-task002-A-agreement`); данные S2 Tables 1–2 (сверены T031). Физические опыты не
входят в поручение; это план, не результат.

## Что сравнить и какое разногласие разрешить

* **Кандидаты:** C72 (PEI с предварительным насыщением CO2, подача 72) и C96 (то же, подача 96).
  **Контроль:** немодифицированный UiO-66-NH2 из той же партии носителя. По желанию третий образец — N72 (без
  насыщения, подача 72): C96 опережает его лишь номинально (порог 2.44 %), а пара C72/N72 даёт контраст способа
  подготовки при той же подаче.
* **Разногласие:** номинальный разрыв C72/C96 3.5 % (3.26 против 3.15 ммоль/г) не разрешён: нужна ограниченная
  относительная погрешность каждого значения < 1.56 % при округлении ±0.005 ммоль/г (без округления < 1.72 %).
  Источник сообщает лишь «< 3 %» для другого сравнения (C72/N72), без повторов. Второе разногласие — давление
  «1 bar» (таблица) против «1 atm» (текст): общее для всех образцов, на ранги не влияет, но влияет на абсолютное q.
* **Если разрыв подтвердится** — C72 предпочтителен ещё и по расходу PEI: удержанный PEI на однократную загрузку
  1 кг CO2 ≈ 1.35 кг против 1.62 кг у C96 (наш производный показатель из авторской оценки PEI Table 1). **Если нет**
  — пара остаётся неразличимой по q, и выбор делается по другим заранее названным критериям (расход PEI, стабильность,
  стоимость), а не по q.

## Протокол (минимум)

1. Одна партия UiO-66-NH2; из неё ≥ 3 независимых приготовления каждого кандидата (повтор синтеза, не только
   повтор измерения) и ≥ 3 аликвоты контроля. Распределение образцов по сериям — до измерений.
2. Сухая равновесная изотерма чистого CO2 при 25.0 °C (термостат с журналом T) на одном волюметрическом приборе;
   одинаковая дегазация (температура, время, вакуум — записать); масса после дегазации.
3. Точки от ~0.05 до ≥ 1.1 bar, чтобы 1.000 и 1.01325 bar были **внутри** измеренного диапазона (интерполяция, не
   экстраполяция) — это снимает разногласие давления.
4. Повтор измерения на той же аликвоте (повторяемость прибора) отдельно от разброса между приготовлениями.
5. Элементный анализ N на тех же образцах (пересчёт удержанного PEI), Vp и BET по N2 при 77 K — для связи с Table 1.

## Что записать

Сырые точки изотерм (p, q, время установления), массы, калибровка свободного объёма, газ (чистота, точка росы),
журнал T, дегазация; повторы раздельно по уровню (прибор / приготовление); бюджет погрешности: общая (калибровка,
давление, масса — одинаковая для всех) и независимая (между приготовлениями). Решение о различимости — по тому же
правилу ограниченных отклонений, с порогом, пересчитанным на новые номиналы; без p-value.

## Перед переносом на PET-derived UiO-66 (проверки носителя и совместимости)

* **Химия закрепления.** Способ S2 разработан для UiO-66-NH2. Если закрепление PEI через глутаровый альдегид
  использует аминогруппы линкера (проверить по §2 S2 до планирования), на UiO-66 из ПЭТ (терефталат без NH2) он
  напрямую не переносится: нужна аминированная форма линкера, смешанные линкеры или сшивка PEI без связи с каркасом —
  каждое — отдельный материал со своим контролем.
* **Носитель:** фазовая чистота и кристалличность (PXRD против эталона), дефектность и состав (TGA, соотношение
  Zr : линкер), BET и объём пор, остаточные примеси переработки ПЭТ (этиленгликоль, катализаторы поликонденсации,
  красители, Na/K), стабильность в воде и в условиях модификации.
* **Контроли:** PET-derived UiO-66 без модификации и UiO-66 из коммерческого линкера, той же процедурой; затем тот же
  протокол сухой изотермы, что выше. Только после этого — влажные опыты.
