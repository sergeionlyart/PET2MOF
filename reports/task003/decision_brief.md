# PET-CO2-TASK-003 — решение: способ модификации PET-derived UiO-66 и границы выигрыша

17.11.2026 · этап v3 · ветка `task003-pet-transfer` · статус: **частично выполнено** (CO₂-ёмкость PET-носителя в
открытых первоисточниках не найдена; карта — условная, не валидированный прогноз). Сухой чистый CO₂, ≈298 K;
S2 — «1 bar | 1 atm», S100 — 0.896 bar; не смесь и не дымовой газ.

## Решение

**Приоритет — R1 (прямое импрегнирование PEI в PET-derived UiO-66); резерв — R2 в форме смешанного линкера
PET-BDC/NH₂-BDC с закреплением через глутаровый альдегид.** R2 в форме S2 (NH₂ каркаса + GA + PEI) к PET-UiO-66
без NH₂ **неприменим** — отклонена эта форма, не маршрут. Выбор сделан по правилу, зафиксированному до расчёта
(`docs/task003/analysis_plan.md` §4, коммит `ab0b074`): у обоих маршрутов есть окно класса B; пороги переноса k*
не различимы при неопределённости основы S100; при равенстве выбран маршрут с меньшей не-PET массой.

| | R1-кандидат | R2-кандидат (резерв) |
| --- | --- | --- |
| Состав | PET-UiO-66 + PEI **по протоколу S100 «30PEI»** (метка 30 %, не выше): удержанная w = 0.231 или 0.300 г/г композита в зависимости от прочтения метки — определить элементным N после дегазации | PET-UiO-66-NH₂ с **f = 0.54** NH₂-BDC в каркасе (подача 50 %, ЯМР SRC-06) + PEI через GA, режим как C72 S2 |
| Аналог (не PET) | S100 30PEI@UiO-66, G = 1.17–1.67 к своему носителю (по четырём ветвям) | S2 C72, G = 1.221 к UiO-66-NH₂ |
| **Порог k*** (g = 1.10, зарегистрированный) | **1.06–1.52** по четырём ветвям основы/метки S100; с погрешностью оцифровки (неполная оболочка) **0.95–1.75** | **1.110** (по округлению 1.106–1.114) |
| Доп. условие | не превышать метку 30PEI: у S100 40PEI (w 0.286–0.40) и S2 I96 (w 0.43–0.45) выигрыш пропадает, G 0.64–1.07 и 0.70 | r = q_M/q_R0 ≥ **0.901** (при k = 1); доступные NH₂ на поверхности не измерены |
| Доля PET среди линкеров / масса PET-фрагментов | 1.0 / 0.36–0.46 | 0.46 / 0.14–0.20 (+ 0.19–0.26 кг покупного NH₂-BDC на кг) |
| ПЭТ на 1 кг сорбента | теор. 0.42–0.53 кг; по выходам SRC-06 0.62–0.73 кг | теор. 0.17–0.23 кг; по выходам 0.25–0.35 кг |
| Контроли | та же партия PET-UiO-66 без PEI; коммерческий UiO-66 того же протокола | тот же смешанный каркас без PEI; GA-only; PET-UiO-66 |

**k = q(PET-носителя)/q(коммерческого аналога).** Если PET-носитель сам сорбирует больше аналога (дефекты: BDC/Zr₆ ≈ 4.4
по ТГА SRC-03), тот же абсолютный вклад PEI даёт меньший относительный выигрыш; при k ≤ k* выигрыш ≥ 10 % сохраняется
при любой блокировке пор φ ∈ [0, 1] в рамках минимального баланса. Устойчиво ко всем ветвям и вершинам оцифровки это
верно только при **k ≤ 0.95**; при 0.95 < k ≤ 1.52 результат зависит от не установленной основы массы S100.

## Что нового по сравнению с TASK-002

1. **Порог переноса k*** — проверяемое численное условие выигрыша PET-композита над собственным носителем (выше).

2. **Окно загрузки R1**: выигрыш в аналогах есть при w ≤ 0.23–0.30 и исчезает к w ≈ 0.29–0.45 (S100 40PEI при w-F/w-C; S2 I96).

3. **Массовый баланс S2 не замыкается**: 19.6–25.0 % массы C72/N72/C96 не являются ни MOF, ни PEI; у C96 этот остаток
   (0.474 г/г MOF) больше подачи чистого GA (0.385 г/г). Интерпретация остатка меняет требуемую η для C72 при φ = 1 и
   g = 1.10 с 0.172 до 0.307 моль CO₂/моль N; при «сухом остатке» C72 требует η = 0.383 > η_lit 0.375 (окна B нет).
   Т. е. сама рецептура-ориентир C72 количественно не объяснена минимальным балансом без знания состава после дегазации.

## Что не доказано

Ёмкость PET-derived UiO-66 по CO₂ (значение 2.06 ммоль/г из аннотации SRC-03 не используется: условия неизвестны);
перенос вклада PEI с аналога на PET-носитель (допущение сценария); тип связи PEI с каркасом; доля мостов MOF–GA–PEI;
влажность, цикл, смесь, синтезируемость. Проверка на невиденных данных отсутствует — это **условная карта**, не
валидированный прогноз. Аналоги S2/S100 не PET-derived; основа массы S100 не установлена.
