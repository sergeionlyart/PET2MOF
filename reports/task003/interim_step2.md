**Что это значит для расчёта.** Численная связь с PET-материалом есть по составу, дефектности и доле аминолинкера,
но не по CO₂. Поэтому карта считается в нормированной форме и для аналогов; PET-`q_host` — одна неизвестная, через
которую сформулировано условие переноса (параметр k = q_PET-носителя / q_коммерческого аналога). Пока эта величина не
измерена или не получена из первоисточника, итог этапа будет «частично выполнено» по критерию (2) поручения.
