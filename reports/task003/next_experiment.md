# TASK-003 — один минимальный следующий опыт

**Цель:** проверить схему переноса PEI-вклада с коммерческого носителя на PET-носитель на **парных образцах одной
лаборатории** и получить k = q(PET-UiO-66)/q(коммерческий UiO-66) — величину, от которой зависит, сохраняется ли
≥ 10 % выигрыш R1. Числа k* из аналога S100 (1.06–1.52 по ветвям при 0.896 bar) — ориентир для проектирования, а не
условие опровержения: знаменатель S100 и его протокол PEI (тип, Mw, основа загрузки) не установлены.

## Образцы (одна партия каждого носителя)

| № | Образец | Роль |
| --- | --- | --- |
| 1 | P0: PET-UiO-66 (BDC из ПЭТ, синтез и активация по SRC-03 или SRC-06) | собственный контроль R0 |
| 2 | C0: UiO-66 из коммерческого BDC, тот же протокол синтеза и активации | знаменатель k |
| 3 | **P1 = P0 + PEI** (разветвлённый PEI, Mw выбрать и зафиксировать; номинальная загрузка как метка «30PEI» S100) | R1-кандидат |
| 4 | **C1 = C0 + PEI** тем же протоколом, та же партия PEI | собственный аналог, даёт G_C |
| 5 | (только если идёт R2) смешанный PET-BDC/NH₂-BDC каркас (f ≈ 0.54) без PEI, с PEI/GA и GA-only | резерв со своим контролем |

## Измерения

Сухие изотермы чистого CO₂, 298 K, ≥ 8 точек до ≥ 1.0 bar; сравнение при одном давлении (0.896 bar для сопоставления
с S100 и 1.0 bar); одинаковая дегазация; ёмкость на массу после дегазации с её фиксацией (масса до и после).
Для 3–5: элементный N на дегазированной массе (N носителя вычитается), ТГА — чтобы получить h, w, s без допущений.
Для 1–2: ЯМР растворённого образца (линкер/модулятор), N₂ 77 K — как контекст, не как φ.

## Проверяемый прогноз

k = q(P0)/q(C0), G_C = q(C1)/q(C0), G_P = q(P1)/q(P0), h = 1 − w − s композита P1. Если перенос верен —
**одинаковые у пары P1 и C1 абсолютный PEI-вклад, w, s и доля сохранённой ёмкости носителя φ** (совместная гипотеза), —
то G_P лежит между значениями при φ = 0 и φ = φ_max = min(1, G_C/h):

G_P ∈ [ G_C/k ; h·φ_max + (G_C − h·φ_max)/k ] (границы упорядочить по величине).

Пример ширины: G_C = 1.17, h = 0.70, k = 1.10 → [1.063; 1.126]. Условия применимости: |w(P1) − w(C1)| ≤ 0.01,
s ≤ 0.02 у обоих. **Опровержение:** G_P вне интервала более чем на 2σ. Это опровергает совокупность допущений
переноса, а не указывает её единственную причину (φ, удержание PEI или η могут отличаться).

Следствие для решения: при k ≥ 1 и k ≤ G_C/1.10 гипотеза даёт G_P ≥ 1.10 при любом φ; при k > G_C/1.10 гарантия для
всех φ утрачивается, но выигрыш ≥ 10 % возможен при большом φ — исход определяет прямое измерение G_P.

## Бюджет точности

≥ 3 независимых приготовления каждого образца. При u(q) = 2 % на значение u(k), u(G) ≈ 2.8 %, и сравнение G_P с
границей интервала (u ≈ 4.9 %) обнаруживает выход за интервал больше ≈ 10 %; для ≈ 5 % нужно u(q) ≈ 1 %. Пограничные
решения округлять наружу. Удержание w — ±0.01 г/г (элементный N ±0.1 мас.%).

## Как меняется решение

| Результат | Решение |
| --- | --- |
| G_P ≥ 1.10 и G_P в интервале | R1 подтверждён на PET-носителе в этой точке; далее влага/цикл (вне этапа) |
| G_P в интервале, но < 1.10 | перенос согласуется, выигрыш мал из-за k; R1 сохраняется только при большем G_C (другой w или PEI) |
| G_P вне интервала | схема переноса опровергнута для этой пары; карта k* не применима, решение — по прямым G_P |
| G_C < 1.10 | протокол PEI не воспроизводит аналог S100; сначала установить протокол (авторы S100), а не переходить к R2 |
| s > 0.02 после дегазации | пересчитать h и требуемую η; балансовая ветвь s = 0 неприменима |
