# TASK-003 — один минимальный следующий опыт

**Цель:** измерить k = q(PET-UiO-66)/q(коммерческий UiO-66) и проверить прогноз выигрыша R1 на собственном
PET-носителе. Это единственная величина, от которой зависит, сохраняется ли ≥ 10 % выигрыш при переносе аналога
(зарегистрированный порог k* = 1.06–1.52 для R1 по ветвям S100, 0.95 с учётом оцифровки в худшей ветви; 1.110 для
R2-ориентира C72).

## Образцы (одна партия носителя на всё)

| № | Образец | Роль |
| --- | --- | --- |
| 1 | PET-UiO-66 (R0): BDC из ПЭТ, водный синтез по SRC-03 или SRC-06 | собственный носитель |
| 2 | UiO-66 из коммерческого BDC, **тот же протокол синтеза и активации** | знаменатель k |
| 3 | **R1-кандидат**: образец 1 + PEI по протоколу S100 «30PEI»; удержанная w (ожидается 0.231 или 0.300 г/г) — по элементному N | проверка прогноза |
| 4 | (по ресурсу) образец 1 + PEI по протоколу «20PEI» | нижняя сторона окна загрузки; «40PEI» не делать — в аналоге выигрыш пропадает |
| 5 | (только если идёт R2) PET-UiO-66-NH₂ f ≈ 0.54 без PEI и с PEI/GA; GA-only | резерв, собственный контроль |

## Измерения

* Сухие изотермы чистого CO₂, 298 K, ≥ 8 точек до **≥ 1.0 bar** (минимум 0.94 bar, чтобы сравнение при 0.896 bar не
  требовало экстраполяции), одинаковая дегазация; ёмкость на **массу после дегазации** с её фиксацией.

* Для образцов 3–5: элементный N на дегазированной массе (N носителя вычитается отдельно), ТГА (летучие / органика /
  остаток ZrO₂), чтобы получить h, w, s без допущения «остаток = сшиватель».

* Для 1–2: ЯМР растворённого образца (линкер/модулятор), N₂ 77 K — как морфологический контекст, не как φ.

## Бюджет точности

≥ 3 независимых приготовления на образец; относительная стандартная неопределённость каждого q ≤ 2 % → k и
G = q₃/q₁ с ≈ ±3 % (1σ). Этого достаточно, чтобы отделить k ≤ 0.95 от k ≥ 1.06 с запасом > 3σ и k ≈ 1.0 от порогов 1.17 и 1.52 и решить G ≥ 1.10 при G ≥ 1.17 или ≤ 1.03 (2σ); отличить k = 1.06 от 1.10 такой опыт **не может** — для этого нужно ≤ 1 % на q и больше приготовлений.
Удержание w — ±0.01 г/г (элементный N ±0.1 мас.%).

## Как меняется решение

| Результат | Решение |
| --- | --- |
| k ≤ 1.06 и G(3) ≥ 1.10 | R1 подтверждён на PET-носителе в этой точке (при 0.95 < k ≤ 1.06 — только в ветвях кроме w-C/b-M с худшей оцифровкой); следующий шаг — образец 4 и затем влага/цикл (вне этого этапа) |
| k ≤ 0.95, w ∈ {0.231, 0.300} ± 0.01, s ≤ 0.05, но G(3) < 1.10 вне 2σ | **прогноз переноса опровергнут**: вклад PEI на PET-носителе меньше, чем у аналога; R1 не отбрасывается, но переносная карта неверна |
| 0.95 < k ≤ 1.52 | решение зависит от основы S100 — сначала её установить (статья S100/авторы); G(3) измерить напрямую |
| k > 1.52 | ≥ 10 % выигрыш R1 не ожидается ни в одной ветви; рассмотреть R2 только при r = q_M/q_R0 ≥ 0.90 и измеренной доступности NH₂ |
| s в образцах 3–5 > 0.05 г/г после дегазации | пересчитать h и требуемую η; балансовая карта в ветви s = 0 неприменима |
