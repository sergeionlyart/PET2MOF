# TASK-003 — один минимальный следующий опыт

**Цель:** на парных образцах одной лаборатории проверить схему переноса PEI-вклада на PET-носитель и измерить
k = q(PET-UiO-66)/q(коммерческий UiO-66). k* аналога S100 (1.06–1.52 при 0.896 bar) — ориентир, не условие
опровержения: знаменатель и протокол PEI S100 (тип, Mw, основа загрузки) не установлены.

| № | Образец (одна партия каждого носителя) | Роль |
| --- | --- | --- |
| 1 | P0: PET-UiO-66 (синтез и активация по SRC-03 или SRC-06) | собственный контроль R0 |
| 2 | C0: UiO-66 из коммерческого BDC, тот же протокол | знаменатель k |
| 3 | **P1 = P0 + разветвлённый PEI** (Mw зафиксировать; номинальная загрузка как «30PEI» S100) | R1-кандидат |
| 4 | **C1 = C0 + тот же PEI** тем же протоколом | собственный аналог, G_C |
| 5 | (если идёт R2) смешанный каркас f ≈ 0.54 без PEI, с PEI/GA, GA-only | резерв со своим контролем |

**Измерения.** Сухие изотермы CO₂, 298 K, ≥ 8 точек до ≥ 1.0 bar; сравнение при одном давлении (0.896 и 1.0 bar);
одинаковая дегазация; q на массу после дегазации (массы до и после). Для 3–5 — элементный N (N носителя вычитается)
и ТГА: оценки h, w, s с указанным методом разделения и неопределённостью. Для 1–2 — ЯМР, N₂ 77 K (контекст, не φ).

**Прогноз.** k = q(P0)/q(C0), G_C = q(C1)/q(C0), G_P = q(P1)/q(P0); h_C, h_P — измеренные доли носителя в C1, P1.
Совместная гипотеза: у P1 и C1 одинаковы абсолютный PEI-вклад на грамм дегазированного композита и доля сохранённой
ёмкости носителя φ. Тогда G_P = G_C/k + φ(h_P − h_C/k), 0 ≤ φ ≤ φ_max = min(1, G_C/h_C), т. е.
**G_P ∈ [min(A, B); max(A, B)]**, A = G_C/k, B — при φ = φ_max. Пример (h = 0.70, G_C = 1.17, k = 1.10):
[1.063; 1.128] (наружу); при k = 0.90 — [1.222; 1.300]. Интервал считается без q(P1); h и протокол фиксируются до
измерения P1. Попадание внутрь — согласие, не измерение φ или η. Если при разных w сохраняется η, а не вклад, нужен
множитель (w_P·n_N,P)/(w_C·n_N,C) — это другая гипотеза, задать заранее.
**Опровержение:** G_P дальше 2σ от ближайшей границы — опровергнута совокупность допущений, без указания единственной
причины. **Следствие:** при 1 ≤ k ≤ G_C/1.10 гипотеза даёт G_P ≥ 1.10 при любом φ; при большем k — только если
max(A, B) ≥ 1.10.

**Точность.** Область 0.8 ≤ k ≤ 1.6; ≥ 3 независимых приготовления; u ≤ 2 % на **среднее** q каждого образца
(разброс приготовлений и систематика). k, G_C, G_P зависимы (общие знаменатели), поэтому σ считается для остатка
R = G_P − граница по четырём q и составам: в примере 2σ ≈ 5.7 % (A) и 6.4 % (B) от границы при точном h (T044r);
u(h) входит в B с весом (1 − 1/k). Превышение 2σ оценкой не гарантирует мощности теста. w — ±0.01 г/г.

| Исход (взаимоисключающие; 2σ по бюджету) | Решение |
| --- | --- |
| G_P вне интервала более чем на 2σ | перенос опровергнут для пары; R1 — только по прямому G_P |
| согласуется и G_P − 2σ ≥ 1.10 | ≥ 10 % выигрыш R1 на PET-носителе установлен в этой точке |
| согласуется и G_P + 2σ < 1.10 | ≥ 10 % в этой точке нет; причину (k, φ, вклад) опыт не разделяет |
| иначе | неразрешимо при данной точности — повторить с меньшей u(q) |
| s > 0.02 у P1 или C1 | сначала пересчитать h и требуемую η |

Сравнение G_C с S100 — отдельный вопрос, не условие оценки пары: PET-композит может пройти порог и при G_C < 1.10.
