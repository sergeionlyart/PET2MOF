# Гипотезы, альтернативы и сравнения (предрегистрация, ред. 1, 2026-11-16)

Зафиксировано до извлечения данных и до любых расчётов. Изменения — только новой редакцией с
причиной; результаты, просмотренные до изменения, перестают быть независимой проверкой.

## H1 (основная)

При фиксированных составе газа (5 мол.% CO2 в сухом CO2/N2) и режиме регенерации зависимость
рабочей ёмкости `q_work = q_ads − q_des` (ммоль CO2 / г сухого композита) от содержания PEI
(0–30 мас.%) имеет внутренний максимум; его положение `w*` и выраженность
`Δ = q_work(w*) − max(q_work(0), q_work(w_max))` зависят от RH (0/40/70 %) и доступности пор.

**Проверяемое следствие H1a:** ранжирование составов по сухой равновесной ёмкости при 35 °C
отличается от ранжирования по рабочей ёмкости во влажном газе (хотя бы одна инверсия пары,
устойчивая к неопределённости).

## Альтернативы (рассматриваются наравне)

* **A1 монотонный рост:** `q_work` растёт с PEI во всём диапазоне (оптимум за пределами 30 %).
* **A2 монотонное падение / преимущество немодифицированного материала:** блокирование пор и
  кинетика перевешивают хемосорбцию.
* **A3 нет устойчивого выигрыша:** различия составов меньше неопределённости прогноза.
* **A4 оптимум есть, но не зависит от RH** в пределах неопределённости.

## Решающее правило (до просмотра результатов)

* Состав считается лучшим, только если `P(rank = 1) ≥ 0.8` в ансамбле Монте-Карло по допустимым
  параметрам и разница с ближайшим конкурентом превышает 95 % интервал разности.
* Сдвиг оптимума с RH считается установленным, если 90 % интервалы `w*(RH=0)` и `w*(RH=70)` не
  перекрываются; иначе — «не установлен» (A4 не отвергнута).
* Итоговый научный статус формулируется одной из трёх формул §11: «гипотеза поддерживается в
  указанных условиях» / «гипотеза не поддерживается» / «данных недостаточно».

## Сравниваемые материалы

| Материал | Роль | Примечание |
| --- | --- | --- |
| UiO-66 (коммерческий/сольвотермальный) | базовый | физсорбция, вода — по измерениям |
| UiO-66 из ПЭТ [S3] | целевая основа | отличие от обычного UiO-66 — только через измеренные дефектность, пористость, примеси |
| UiO-66-NH2 | контроль функционализации | |
| PEI@UiO-66-NH2 [S2] | **отдельный контрольный материал** | не отождествлять с PEI@UiO-66 из ПЭТ |
| PEI@UiO-66 (целевой) | прогноз | влажных измерений, вероятно, нет ⇒ статус «проверяемый прогноз» |

Метрики ошибки и допуски для контрольного воспроизведения и проверочных серий фиксируются в
`docs/validation_protocol.md` до просмотра проверочных серий (этап 1).
