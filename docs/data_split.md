## Следствие для научного статуса

Количественной независимой проверки влажного эффекта на PEI@UiO-66 нет. Поэтому любые выводы о
сдвиге оптимума PEI с влажностью получат статус **«проверяемый прогноз»** (§7 поручения), а не
валидированный результат. Проверяемо на независимых данных: (а) сухая физсорбция носителя при
27–35 °C; (б) перенос PEI-модели с S100 на S2 (качественно разные материалы — граница переноса);
(в) правило конкуренции CO2/H2O на носителе (если S102/Madden будут извлечены).
