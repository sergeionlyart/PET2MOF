## Ограничения слепоты

* Руководитель **видел** численные значения S2 Table 1–2 (включая колонку «moist») до фиксации модели
  (проверка доступа к источнику 2026-11-16). Поэтому S2 — проверка переноса, выполняемая
  субагентом-разработчиком, которому S2-числа не передаются; решение о допусках принимается
  до запуска проверки и фиксируется тегом.
* Аудитор T001 видел графики проверочных серий; разработчику модели (T012/T014) их числа не передаются.
* Проверочные серии загружаются в код только скриптом `scripts/validate.py` после тега `prereg-v1`.
