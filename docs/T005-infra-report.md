## Блокер проверки публикации

Буквальная проверка отмечает строки в самой карточке T005, коде проверки, фильтре
редактирования и фиктивных тестовых данных. Ни один такой результат не объявлен
прошедшим автоматически: правила карточки требуют строгого поиска. Значения в вывод
проверки не включаются. На момент разбора было пять неуспешных проверок: четыре категории
текстовых правил и Gitleaks по истории.

Сканирование рабочего дерева Gitleaks и staged-проверка прошли. При сканировании **всех**
refs обнаружено 639 срабатываний `generic-api-key` в коммите
`c07cb171bd7e9cb739ae814ae0966958004d7890` другой ветки: 637 на публичные NIST-ID
в JSON-поле `hashkey`, ещё два в скриптах сохранённой HTML-страницы NIST. Это не доказательство
утечки ключей владельца; исключать находки без разбора также нельзя. Файлы и история
той задачи не изменялись. Для снятия блокера руководителю нужно согласовать точные,
проверенные исключения для синтаксических примеров и публичных идентификаторов либо
изменить исходные требования к буквальному поиску. Исполнитель исключения не добавлял.

## Ограничения

- Облачные клиенты проверены только заглушками, без установки extra и без внешних вызовов;
  тарифы, доступность моделей, удалённые права и совместимость с реальным сервисом не подтверждены.
- Google readiness проверяет локальные credentials без сетевого обнаружения, а не удалённые IAM-права.
- После неоднозначного сбоя попытка оплачена в ledger; зависшие резервы и остановленный бюджет
  требуют ручного разбора. После остановки автоматического сброса или смены провайдера нет.
- Кэш псевдонима latest автоматически не переиспользуется. Неизвестная фактическая версия
  оставляет raw-ответ приватным и завершает извлечение ошибкой.
- Очистка произвольных новых полей API не может заменить ручной просмотр публичного пакета.
  Права файлов не изолируют процессы одного пользователя.
- Автоматическая нарезка регионов облачного PDF и неопределённость калибровочных точек
  оцифровки не реализованы; поддерживается выбор целых страниц и ошибка считывания маркеров.
- Научные reproduce/report остаются заглушками; smoke — проверка инфраструктуры, не научный результат.
