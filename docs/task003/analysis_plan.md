## 0. Условия и смысл выигрыша

* Сухой чистый CO₂, ≈298 K. S2 — «1 bar | 1 atm» без пересчёта (E-05 TASK-002). S100 — общее наибольшее давление,
  при котором измерены все пять изотерм, **0.896 bar** (UiO-66 выше не измерен); значение берётся кусочно-линейной
  интерполяцией точек оцифровки (метод, сохранённый в TASK-002 Б); экстраполяция запрещена. Результат для смеси и
  дымового газа не заявляется.
* Выигрыш `G = q_comp / q_target_ref`; проектный порог `g ∈ {1.00, 1.10}` (10 % — сценарий полезного выигрыша, не
  установленный эффект). Сравнения: R1 — с R0 (тот же носитель без PEI); R2 — с **собственным** смешанным носителем M
  без PEI и отдельно с R0.
* Все `q_comp` — на массу сухого композита. Основа S100 не установлена → две явные ветви чтения (§2.3).

## 1. Балансовая схема (одна основная)

`h + w + s = 1`, `h, w, s ≥ 0`; `q_comp = h·φ·q_host + w·n_N·η + s·q_s`, `q_s = 0` в минимальной ветви.
`η_min = (g·q_ref − h·φ·q_host)/(w·n_N)` при `w > 0`; `w = 0` — отдельно (`G = h·φ` ≤ 1 при s ≥ 0, φ ≤ 1).
φ ∈ [0, 1] (только блокировка); φ > 1 — отдельная гипотеза, не используется без независимого обоснования.
η — дополнительная сухая сорбция на моль **всего** N PEI; дополнительно сообщается η на моль первичного+вторичного
N, если T041 обоснует долю третичных. Азот NH₂-линкера в N PEI не входит. Сорбция NH₂-носителя учитывается только
через `q_host` собственного носителя (один раз).

`n_N` — из источника: S2 использует N(PEI) = 30.74 мас.% (→ 21.95 ммоль N/г); теоретическое для (C₂H₅N)ₙ 32.52 мас.%
(→ 23.22 ммоль/г) — граница диапазона. Для S100 тип/Mw PEI — по T040; при `unknown` — тот же диапазон.

## 2. Входы и их классы происхождения

1. **Измерения/оценки авторов S2** (Table 1–2): q, W (прирост массы на 1 г MOF), N элементный, PEI_exp (авторская
   формула, проверяется воспроизведением на Table 1). Состав на 1 г: `h = 1/(1+W)`, `w = PEI_exp`, `s = 1 − h − w`.
   **Две ветви для s** (решение не выбирается заранее): (s-I) s — сохраняющийся сухой остаток (GA/олигомеры), состав
   как выше; (s-V) s — летучая часть, удаляемая дегазацией; отношение PEI:MOF сохраняется:
   `r = PEI_exp·(1+W)` (г PEI на 1 г MOF), `h' = 1/(1 + r)`, `w' = r/(1 + r)`, s' = 0. Промежуточные доли — диапазон.
2. **S100** (оцифровка, основа не установлена): q при 0.896 bar; ветви (b-C) все q на массу композита; (b-M) все q
   на массу MOF → `q_comp = q·(1−w)` для PEI-образцов. Доля w: (w-C) метка = мас.% композита; (w-F) метка = мас.% от
   MOF → `w = x/(100+x)`; выбирается по T040, иначе обе. s = 0 (импрегнирование без сшивателя).
3. **Литературные аналоги и стехиометрия η** — таблица T041 (`data/task003/eta_bounds_T041.csv`), классы
   `stoichiometric_ceiling` / `literature_analog_measured` / `project_scenario` не смешиваются.
4. **PET-специфичные данные** (T040): SRC-03 SI (PET vs BDC, одна лаборатория: BET, объёмы, BDC/Zr₆), SRC-06 SI
   (выход BDC из ПЭТ, конверсия, доля NH₂-BDC в каркасе по ЯМР против загрузки, дефектность). **CO₂ `q_host` PET-носителя
   — `unknown`** (основной текст SRC-03 недоступен). Значение из аннотации в расчёт не входит. Если первоисточник будет
   получен, значение вводится одной строкой (T, p, основа, активация, образец) без изменения правил ниже.
5. Проектные сценарии: φ-сетка, k, r (ниже) — помечаются `project_scenario`.

## 3. Расчёты

**А. Материальный баланс** (`material_balance.csv`): на 1 г композита — h, w, s по S2 и S100 (все ветви); проверка
суммы = 1 и неотрицательности; азотный баланс (N линкера ≠ N PEI); подача PEI против удержания (S2 feed/W/PEI_exp);
на 1 кг композита — MOF, PEI (подача и удержание), линкер (по формуле Zr₆O₄(OH)₄L₆ и по дефектному составу
SRC-03/SRC-06 — оба), ПЭТ: теоретический предел (BDC 166.13 г/моль на звено 192.17 г/моль) и сценарий по измеренным
выходам SRC-06 (извлечение BDC, конверсия в MOF); GA — подача отдельно, остаток только как ветвь s-I. Доли:
PET-происхождение среди линкеров (R1: 1; R2: 1 − f, f — доля NH₂-BDC **в каркасе** по ЯМР SRC-06) и массовая доля
PET-фрагментов во всём сорбенте. Ни одна доля не означает «композит из отходов».

**Б. Карта** (`design_window.csv`): η_min на сетке w ∈ [0, 0.50] (шаг 0.01), φ ∈ [0, 1] (шаг 0.01), s ∈ {0, s(S2 C72,
s-I)}, g ∈ {1.00, 1.10}, в нормированной форме `η_min·n_N/q_host = (g − h·φ)/w` и в абсолютной для
q_host ∈ {аналог S2 BASE 2.67 (UiO-66-NH₂); аналог S100 UiO-66 при 0.896 bar; PET — `unknown`}. Классы клеток:
A — η_min ≤ 0 (PEI не нужен); B — 0 < η_min ≤ η_obs_max (наибольшая η среди допустимых линий аналогов при φ ∈ [0,1]
и в литературе T041 при сопоставимых условиях); C — η_obs_max < η_min ≤ η_ceiling (стехиометрия); D — η_min > η_ceiling.
Граница — в замкнутой форме `φ_crit(w; η) = (g − w·n_N·η/q_host)/h`; сетка только для рисунка; совпадение сетки с
замкнутой формой проверяется (|Δ| < 1e-9). Наложить **допустимые линии** (φ, η) аналогов: S2 (все образцы, ветви s-I/
s-V), S100 (все ветви основы и w).

**Перенос аналога на PET-носитель (сценарий, не измерение).** Если абсолютный вклад PEI `w·n_N·η` при тех же w, s
переносится с аналога, а собственная ёмкость PET-носителя `q_host,PET = k·q_host,analog`, то
`G_PET = h·φ·(1 − 1/k) + G_analog/k`. Для каждой допустимой точки линии аналога — интервал G_PET по φ ∈ [0,1].
Порог `k*(g)` — наибольшее k, при котором `G_PET ≥ g` для всех φ ∈ [0, 1] (в замкнутой форме), и φ-зависимая граница.
k — проектный параметр (диапазон 0.8–1.5 для рисунка), измеряемый величиной `q_R0,PET / q_UiO-66,commercial`.

Для R2 дополнительно `r = q_M / q_R0` — неизвестен (линейное смешение запрещено); результат сообщается как условие на r.
Доступность NH₂ для закрепления (T041 §2) — отдельное ограничение R2.

**В. Устойчивость.** Детерминированно; погрешности по происхождению: округление S2 ±0.005 ммоль/г и ±0.05 мас.% (N, PEI),
±0.5 п.п. W; оцифровка S100 по полуширинам TASK-002 (q ±0.105, p ±0.042 bar); диапазон n_N; ветви s и основы.
Общие систематические (основа, n_N, интерпретация s) и индивидуальные (оцифровка/округление каждой серии) — раздельно,
вершинным перебором. Чувствительность: какой параметр сильнее меняет k* и η_min (размах по диапазону каждого при
прочих номинальных). Вероятности не вычисляются; равномерные распределения на незнании не вводятся.

## 4. Правило выбора маршрута (до расчёта)

1. Маршрут, химически несовместимый с PET-носителем в рассматриваемой форме (T041), отклоняется **в этой форме**.
2. Для совместимых маршрутов: при k = 1 и g = 1.10 — есть ли точки класса B на допустимых линиях аналогов; затем k*.
3. Приоритет — маршрут с непустым окном B и бо́льшим k* (устойчивее к неизвестной ёмкости PET-носителя); при равенстве
   (|Δk*| < размаха k* по §3В) — маршрут с меньшей не-PET массой на 1 кг сорбента. Если окна пусты у обоих — отрицательный
   результат в установленной области. Если решение зависит от неизмеренного параметра — рекомендация условная, с порогом.
4. Новый проверяемый прогноз формулируется по k* (или φ_crit) с условием опровержения и измерением, которое его проверяет.

## 5. Что не делается

Нет подгонки φ и η по одной ёмкости (только допустимые линии); нет φ = отношению BET/объёмов N₂; нет GCMC; оператор
пористости v1 (`src/pet2mof/calibration/`) **не используется** в этом этапе; нет вероятностей; нет заявлений о влажном
режиме, цикле, смеси, синтезируемости.

## Поправки

**P3-01 (17.11.2026, до учитываемых расчётов T042; после независимого пересчёта T043 на тех же определениях).**
Причина: T043 показал, что при k ≥ 1 минимум `G_PET` по φ ∈ [0, 1] достигается при φ = 0, поэтому зарегистрированный
`k*_all(g) = G_analog/g` не зависит от состава h. Зарегистрированное определение и правило §4 **не меняются**.
Дополнительно (только как чувствительность, не для правила выбора) сообщаются: `k_crit(φ) = (G_analog − hφ)/(g − hφ)`
при g > hφ и `k*_adm` — минимум k_crit по допустимому отрезку линии аналога, где 0 ≤ η(φ) ≤ η_ceiling; если такого
отрезка нет, ветвь помечается «минимальный баланс несовместим с потолком η». Потолки η — из принятого
`data/task003/eta_bounds.csv` (T041), фиксируются коммитом до запуска T042.
