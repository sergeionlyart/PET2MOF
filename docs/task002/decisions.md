# Решения этапа v2 (PET-CO2-TASK-002)

Нумерация отдельная от v1 (`docs/decisions.md`, D-01…D-18, не меняется).

* **E-01 (17.11.2026).** Этап v2 ведётся на ветке `task002-dry-screening`; входы — `data/task002/`, выходы —
  `reports/task002/`, паспорта — `runs/`. v1 не перезаписывается.
* **E-02.** Два файла поручения с именем владельца не входят в Git-копию пакета (`docs/task002/intake.md`).
* **E-03.** Правила анализа А/Б/В фиксируются `docs/task002/analysis_plan.md` коммитом до расчётов исполнителей.
  Изменение правил после просмотра результатов — новая запись E-xx с причиной; прежний результат сохраняется.
* **E-04.** Сценарии ±3/5/10 % — проверки устойчивости решения, не измеренные неопределённости; вероятности не
  вычисляются (поручение §4.1). Правило P(rank=1) из v1 здесь не применяется.
* **E-05 (после расчётов, по T035-01).** Разногласие давления 1 bar / 1 atm не трактуется как общий множитель q;
  k — только назначенный общий множитель ёмкости. Поправка внесена в план отдельным блоком (предрегистрация
  сохранена), в решение, план опыта и как пометка к промежуточному выводу. Числа А не меняются.
* **E-06 (по T035-02, T035-03).** Бюджет погрешности следующего опыта разделяется на общую (с обоснованием),
  индивидуальную и состояния образца; химия закрепления S2 описана по §2.1 источника с ограничением идентификации.
