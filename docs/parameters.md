# Параметры модели M1 и базовой B1 — T012, редакция 1

Дата: 2026-11-16. Это реестр **спецификации**, не заполненный результат подгонки.
Уравнения — [model_spec.md](model_spec.md); критерии — [validation_protocol.md](validation_protocol.md).
`unknown` не заменять нулём. `fit_on_C` означает «подлежит оценке на разрешённых C»,
а не «уже оценён». Тип не заменяет статус данных: до независимой проверки исходная
запись остаётся `provisional`, даже если опубликована в таблице. Основной fit возможен
лишь на `verified`; предварительный — только явно помеченная чувствительность.

Нельзя независимо оценивать q_W,max по воде и одновременно свободно подгонять
V_p,0 того же образца, сохраняя (9): эти величины связаны плотностью. Для разных
статей/партий их связь — перенос, а не общая измеренная константа. До получения
порометрии модель не даёт уникального физического разложения S100.
