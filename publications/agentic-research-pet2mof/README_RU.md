# Статья «Агентская система в работе исследователя» — комплект для согласования

**Статус:** черновик для согласования (PET-CO2-TASK-004). Не опубликован; публикация, перенос на сайт, push и CI
требуют отдельной команды владельца. `noindex` не защищает доступ: не выкладывайте `index.html` на открытый хост до
согласования.

## Как открыть

Откройте `index.html` двойным щелчком (браузер, без сети и сборки). Изображения лежат в `assets/` рядом — переносите
каталог целиком. Пересобрать страницу из источника:

```sh
python3 -I tools/build.py
python3 -I tools/check.py
```

(из этого каталога; нужен Python ≥ 3.11 со стандартной библиотекой). Рисунки пересобирает
`tools/make_figures.py` (нужен matplotlib из окружения проекта: `../../.venv/bin/python -I tools/make_figures.py`).
Проверка точности цитат промптов: `python3 -I evidence/check_excerpts.py` (нужна история Git проекта).

## Что внутри

| Путь | Что это |
| --- | --- |
| `index.html` | готовая статья для просмотра (генерируется из `article.ru.md`) |
| `article.ru.md` | единый редактируемый источник (подмножество Markdown импортёра сайта) |
| `article.metadata.json` | статус, язык, заголовок, slug, версия, подпись |
| `assets/` | 7 рисунков: PNG для статьи и SVG-исходники; шрифтов нет |
| `prompts/` | P01–P07 — исторические промпты (копии из Git), P08 — новый учебный шаблон |
| `evidence/` | хронология, реестр утверждений, манифесты промптов и рисунков, учёт запусков, источники версий, записки об уборке репозитория и интеграции с сайтом |
| `review/` | независимое ревью, проверка комплектности, проверка HTML и скриншоты |
| `tools/` | сборщик, проверка, тесты, генератор рисунков |

## Что передать на сайт

`article.ru.md`, `article.metadata.json`, PNG из `assets/` — по порядку импорта сайта (см.
`evidence/site_integration.md`: соответствие разметки, приложение с промптами, решение о локалях).
