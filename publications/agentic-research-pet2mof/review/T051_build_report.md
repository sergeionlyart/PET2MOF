  Основной текст, рисунки, таблицы и ссылки не требуют JavaScript. Приложения — native details.
- `tools/check.py`: stdlib-проверка HTML, Markdown, файлов, якорей, приватных шаблонов и GitHub-ссылок.
  GitHub-пути проверяются только локальным `git ls-tree`, без HTTP.

  Отдельная конфигурация pytest сохраняет временные файлы внутри разрешённого `tools/`.
- `tools/index.html`: **тестовая фикстура, не статья**. `tools/assets` — относительная
  символическая ссылка `../assets`, чтобы локальный HTML фикстуры находил рисунки без дублирования.
  При переносе фикстуры нужно сохранять symlink либо копировать туда `assets/`.
- `tools/make_figures.py`, семь пар PNG/SVG в `assets/`, 14 строк `evidence/assets_manifest.csv`.
- `tools/figure_checks.json`: SHA-256 входов, размеры, параметры и численные сверки отрисовки.
  Это свидетельство преобразования готовых результатов, не паспорт нового научного запуска.
- `tools/.gitignore`: только локальные cache/bytecode/test/profile внутри `tools/`.

### Контракт metadata и дальнейшая сборка статьи

Рядом с `article.ru.md` требуется `article.metadata.json`, объект с непустыми строками
`eyebrow`, `subtitle`, `author`, `date`, `version`, `reading_time` (пример — sample.metadata.json).
Дополнительные поля JSON допускаются; текст H1 берётся исключительно из Markdown.
Никакая фиктивная дата или оценка чтения автоматически не генерируется.
Без аргументов инструменты используют пути относительно расположения скрипта, не cwd:

```sh
../../.venv/bin/python -I tools/build.py
../../.venv/bin/python -I tools/check.py
```

Это будущая команда руководителя: она создаёт `index.html` рядом со статьёй.
В T051 эти команды без аргументов не запускались: статьи ещё нет, а запись в корневой
`index.html` публикации вне разрешённых исполнителю путей.
Markdown ограничен диалектом карточки; произвольный HTML и расширения не пропускаются.
YAML поддерживает простые скалярные значения и уникальные ключи, без вложенных коллекций/aliases.
Синтаксические ошибки завершаются exit 1 и диагностикой строки.
`ARTICLE_PRIVATE_PATTERNS` читает только check.py из окружения, `.env` он не открывает.
