# PET2MOF — вычислительное исследование сорбента CO2 из отходов ПЭТ

Статус: **этап 0 (подготовка и реализуемость)**. Подробности — в `docs/plan.md`.

## English summary

Open computational study of CO2 capture by UiO-66-family MOFs whose linker can be obtained from
recycled PET, modified with polyethyleneimine (PEI). Question: does the CO2 working capacity from
humid 5 % CO2/N2 at 35 °C, 1 bar show a PEI-loading optimum whose position depends on humidity
and pore accessibility? Work order: `docs/work_order_v1.1_RU.md`. All checks run locally;
no GitHub Actions / external CI is used. Results are predictions unless explicitly validated.
