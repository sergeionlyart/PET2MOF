## Шаги

1. **Слепая контрольная оцифровка.** Отрисуйте страницы с рисунками из PDF сами (PyMuPDF), откалибруйте оси
   по делениям сами и для **каждой** из 19 серий снимите ≥ 8 маркеров по всему диапазону (включая начальный
   участок и плато) своим способом (не используя `scripts/extraction/digitize_c_series.py` и CSV T011).
   Сохраните проект (изображение/SHA-256, калибровка, пиксели) в `data/extraction/digitization/T011v-*`.
2. **Сопоставление.** Затем сравните с CSV T011 (ближайший сосед по x): максимум и медиана |Δq|, |Δp|
   по сериям против заявленных T011 погрешностей. Отдельно проверьте **соответствие серий легенде**
   (материал ↔ маркер/цвет), температуры и газ каждой панели, полноту маркеров (пропуски/дубликаты/точки
   с линий подгонки), ветви адсорбции/десорбции S106.
3. **Пересчёты.** p_sat воды при 293 K по IAPWS SR1-86 (официальный документ), константа 22.414 cm3(STP)/mmol,
   кПа→бар для S100, единицы и столбцы `data/processed/c_series/*.csv`, роли `C`/`C_candidate`/`context_GO`/
   `sensitivity_only`; отсутствие V-источников; Table 3 помечена `author_fit` и не попала в измерения.
   Проверьте условия в тексте статей (активация S105 §2.3 vs §3.4, диапазон N2; S106 активация, 293 K).
4. Прочитайте отчёт T011 и отметьте расхождения с ним.
