## Цель

Инструменты, которые из одного UTF-8 Markdown-файла `publications/agentic-research-pet2mof/article.ru.md`
(пишет руководитель; пока его нет) собирают автономную страницу `index.html` в оформлении блога Dobrovola.dev, и
5–7 иллюстраций по зафиксированным данным. Поручение статьи — `docs/work_order_task004_RU.md` §§6–7, 11.

## 1. Сборщик `tools/build.py` (stdlib, `python -I`)

Вход: `article.ru.md` + `article.metadata.json` (рядом). Выход: `index.html` (рядом). Без сети, без JS-зависимостей;
основной текст читается при отключённом JavaScript; все ресурсы — относительные `assets/...`; CSS — встроенный.

**Поддерживаемое подмножество Markdown (совпадает с импортёром сайта; всё остальное — ошибка с номером строки):**
необязательный YAML-блок `---`…`---` с уникальными скалярными ключами в начале; ровно один `# H1` (заголовок);
`##`/`###`; абзацы; `**strong**`, `*em*`, `` `code` ``; ссылки `[t](https://…)`, `[t](#anchor)`, `[t](relative/path)`;
`---` разделитель; простые маркированные `- ` и нумерованные `1. ` списки без вложенности; цитата `> `; fenced code
(``` и ````, с языком или без; внутри — дословно, без разбора); простые pipe-таблицы; однострочные сноски
`[^n]` + `[^n]: текст`; изображение отдельной строкой `![alt](assets/x.png)` и **следующая строка** `*Рис. N. …*` —
это figure с figcaption. Сырой HTML, вложенные списки, task lists, Setext, definition lists запрещены (ошибка).

**Разметка страницы (стили — заново, по токенам ниже; исходный CSS сайта не копировать):**
* цвета: фон `#f8f7f3`, белый `#fff`, текст `#121212`, вторичный `#5c5c59`, линия `#9d9d98`, тонкая линия `#d5d4ce`,
  синий `#0755dc` (hover/текущий пункт/фокус), тёмно-синий `#003fae`, красный `#d91922` (метка черновика);
* шрифты (системные, без файлов): чтение `Georgia, "Times New Roman", serif`; интерфейс `"Helvetica Neue", Arial,
  sans-serif`; код и метки `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`;
* ширины: чтение 740px; страница `min(1380px, calc(100vw - 64px))`; `body` min-width 320px, line-height 1.5;
* шапка статьи (max-width 1000px, нижняя граница 1px текстом): eyebrow — monospace 11px uppercase («Исследовательская
  практика / агентная инженерия» — брать из metadata); H1 — Georgia 500, `clamp(40px, 8vw, 96px)`, letter-spacing
  −0.035em, line-height ~0.9; подзаголовок — Georgia 21px; строка meta — monospace 10px uppercase (автор, дата,
  версия, время чтения); заметная метка **«Черновик для согласования»** (красная рамка/текст, monospace);
* раскладка: сетка `220px | minmax(0, 740px)`, gap `clamp(48px, 9vw, 130px)`; слева sticky-оглавление «На этой
  странице» (H2; H3 — с отступом 14px, 11px, вторичный цвет; ссылки 12px, верхняя граница 1px, без подчёркивания);
  ≤ 900px — одна колонка, оглавление в потоке перед текстом, 2 колонки пунктов; ≤ 620px — 1 колонка;
* текст: Georgia 19px / 1.55; H2 — Georgia 500 `clamp(31px, 4vw, 43px)`, line-height 1.03; H3 — интерфейсный 18px;
  блок «Кратко» (первый H2 с этим названием) — рамка сверху и снизу 1px, заголовок monospace 12px uppercase;
  ссылки наследуют цвет, подчёркивание 1px, offset 0.18em, hover синий; `:focus-visible` — outline 3px синий,
  offset 3px; код-блоки — рамка 1px, padding 18px, `white-space: pre-wrap; overflow-wrap: anywhere`; таблицы —
  в обёртке с `overflow-x: auto` (прокрутка только внутри), UI-шрифт 14px, th monospace 10px uppercase на белом;
  figure — img 100% с рамкой 1px, figcaption monospace 11px вторичным цветом;
* **приложения:** каждый `###` внутри `## ` с заголовком, начинающимся на «Приложение», становится
  `<details id=…><summary>…</summary>…</details>` (summary — UI-шрифт 600, min-height 52px, рамка сверху);
  якорь `#id` ведёт на details; маленький inline-скрипт (необязательный) открывает details при переходе по якорю;
  без JS details просто закрыты, но заголовок и якорь доступны;
* print: скрыть оглавление; белый фон; одна колонка; **все details раскрыты** (`details > *` видимы; при
  необходимости — `beforeprint`), таблицы и код не обрезаются; после внешних ссылок печатать URL;
* `<html lang="ru">`, `<meta name="robots" content="noindex,nofollow">`, viewport, charset; уникальные `id` у H2/H3
  (транслитерация или из `{#id}` нельзя — генерировать детерминированно из текста, кириллица допустима в id;
  повторы — суффикс); без аналитики, форм, внешних шрифтов/скриптов/изображений; ссылки на внешние сайты — обычные
  `<a>` (это не загрузка ресурса).
* сноски — список в конце статьи с обратными ссылками.

## 2. Проверка `tools/check.py` (stdlib)

Код выхода ≠ 0 при нарушении: ровно один `<h1>`; уникальные id; все `href="#…"` существуют; все локальные `src`/`href`
существуют; у каждого `<img>` непустой alt и figcaption; нет `<script src>`, `<link rel=stylesheet href>` на внешний
хост, `@import`, `url(http…)`, `<iframe>`, `<form>`; есть `noindex,nofollow` и метка черновика; Markdown проходит
парсер без ошибок; число слов **основного текста** (от H1 до первого H2 «Приложение…», без код-блоков и таблиц) —
печатать и предупреждать вне 4000–6000; каждая ссылка `https://github.com/sergeionlyart/PET2MOF/blob|tree/<sha>/…`
использует один из трёх зафиксированных sha (`66bae26a…`, `1558433…`, `70685dc…`, полные 40 символов) и путь
существует в `git ls-tree` этого commit; поиск персональных данных (список шаблонов передаёт руководитель через
переменную окружения `ARTICLE_PRIVATE_PATTERNS` — регулярные выражения через `|`; если не задана — пропуск с
предупреждением). Сделать фикстуру `tools/sample.ru.md` + `tools/sample.metadata.json`, покрывающую все элементы,
и тесты `tools/test_build.py` (pytest или unittest; запуск — `python -I -m pytest tools/test_build.py` из `.venv`).
