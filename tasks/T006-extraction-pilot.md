## Шаги

1. **До сравнения** записать в `reviews/document_extraction_benchmark.md` проверяемые поля и допуски
   (числа: точное совпадение строк значений и единиц; знаки/степени/индексы: точное; связь
   «ячейка—заголовок» и «кривая—материал—условия»: точное; оцифровка: допуск задаётся в единицах
   данных из пиксельной погрешности калибровки).
2. Выборка **15–20 содержательных страниц** из реально используемых источников (приоритет —
   записи с ролью `calibration`/`validation`): обычный текст, многоколоночная вёрстка, таблицы
   (BET, объём пор, ёмкость CO2 vs загрузка PEI), формулы, графики изотерм; сканы — если есть.
   Список страниц, SHA-256 PDF/HTML, номер страницы PDF ↔ печатный номер — в отчёт.
3. Локальный путь: (а) HTML/XML полного текста PMC или издателя — таблицы из HTML; (б) текстовый
   слой PDF (PyMuPDF/pdftotext) с постраничной оценкой; (в) tesseract только на проблемных страницах.
   Docling/GROBID — только если (а)–(в) не дают таблиц/структуры; обосновать.
4. Эталонная разметка: значения из **отрисованной** страницы (рендер PNG 200–300 dpi сохранить в
   `private/renders/` — не публикуется), проверка вручную по изображению. Эталон не должен состоять из
   ответа другой LLM без сверки с изображением. Для каждого поля — где на странице.
5. Сравнение: доля верных чисел, знаков/степеней, единиц, связей; пропуски; трудоёмкость исправлений.
6. Пробная оцифровка 1–2 рисунков изотерм (самый важный рисунок для калибровки): изображение из OA
   источника (хеш), калибровка осей по ≥ 2 делениям на ось с пиксельными координатами, автоматическое
   выделение маркеров по цвету/форме (скрипт в `scripts/extraction/`), наложение извлечённых точек на
   изображение (`private/renders/overlay_*.png` + уменьшенная публикуемая копия, если лицензия CC BY),
   проект `data/extraction/digitization/<extraction_id>.digitization.yaml`, экспорт CSV, оценка
   погрешности калибровки и считывания. Разделять маркеры, линии подгонки, полосы ошибок.
7. Паспорта `data/extraction/records/<extraction_id>.yaml` (схема T005) со статусом `provisional`
   (до проверки T007).
8. Решение: достаточен ли локальный путь; нужен ли внешний OCR (если да — какие страницы, почему;
   вызов не выполнять). Записать в `reviews/document_extraction_benchmark.md`.

## Критерии приёмки

* 15–20 страниц, допуски записаны до сравнения, эталон привязан к изображению страницы.
* Хотя бы один рисунок оцифрован с проектом, калибровкой, наложением и оценкой ошибки.
* Ни одного числа без указателя на страницу/таблицу/рисунок.
