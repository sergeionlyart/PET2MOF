## Цель

Собрать фактические официальные рекомендации OpenAI по выбору моделей и уровня рассуждений для
матрицы `docs/model_policy.md`.

* S10 https://developers.openai.com/api/docs/models/gpt-6-astra
* S11 https://developers.openai.com/api/docs/models/gpt-6.1-sol
* S12 https://developers.openai.com/api/docs/models/gpt-6.1-terra

* при необходимости официальная страница о reasoning effort в Codex / API.

## Артефакт

`docs/model_policy_sources.md` (русский): для каждой страницы — URL, дата/время доступа (UTC),
HTTP-статус, заголовок; для каждой модели — назначение по официальному описанию, поддерживаемые
уровни reasoning effort, рекомендации по выбору уровня, контекст/ограничения, если указаны.
Короткие цитаты (≤ 15 слов) только в кавычках; остальное — пересказ. Отдельно — что на страницах
**не** сказано (например, нет гарантий пригодности для научных расчётов).
