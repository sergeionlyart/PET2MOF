| Поле | Значение |
| --- | --- |
| task_id | T045-task003-clean-repro |
| Исполнитель | gpt-6.1-terra, reasoning effort **medium** |
| Сеть | off |
| Проверяющий | руководитель |
| Ограничения | Отдельный чистый клон ветки `task003-pet-transfer` на зафиксированном руководителем коммите. Не делать commit. Не менять отслеживаемые файлы (выходы сравнивать во временном каталоге или по `git diff`). Не читать `.env` (его нет), не использовать сеть, LLM, платный OCR. 1. Записать коммит, версии Python/uv, наличие `.venv` (создан руководителем из `uv.lock` офлайн).
2. Выполнить: `make task003-test`, `make task003-reproduce` (из чистого дерева, через `scripts/run.py`),
   `python scripts/task003_independent/recompute.py` (как указано в `reviews/T043_report.md`), `make report-task003`,
   `make test`.
3. Сравнить созданные выходы с закоммиченными: CSV/JSON — побайтово, кроме полей `run_id`/времени (перечислить, что
   отличается и почему); PNG — по пикселям вне полосы подписи с run_id; PDF — указать, отличается ли и где.
4. `reviews/T045_repro_report.md` (рус.): команды, коды выхода, время, расхождения с причинами. Неудачи не скрывать.
