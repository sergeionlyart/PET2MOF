| task_id | T004-audit-check |
| Исполнитель | gpt-6.1-sol, reasoning effort **medium** (проверка информации по первоисточникам) |
| Сеть | on |
| Проверяющий | руководитель |
| Ограничения | Только текущая директория. Не делать git commit. Не изменять `sources/registry.yaml` — только писать отчёт. |

## Цель

Независимо проверить `sources/registry.yaml` (составлен другим агентом) по первоисточникам.
Выводы автора реестра (`sources/audit_report.md`) **не читать до завершения собственной проверки**,
чтобы не заякориться; затем сравнить.

## Шаги

1. Для **каждой** записи: DOI через `https://api.crossref.org/works/<DOI>` — совпадают ли заголовок,
   первый автор, год, журнал. Отметить расхождения.
2. Для каждой записи с ролью `calibration` или `validation` и для S1–S3: открыть законно доступный
   полный текст (PMC, издатель OA, SI) и проверить, что указанная таблица/рисунок существует и содержит
   заявленные величины и условия (T, p_CO2, RH, загрузка PEI, нормировка). Записать номер страницы/
   раздела, где это видно.
3. Проверить заявленные лицензии (CC BY / CC BY-NC / закрыто) по странице статьи.
4. Найти пропущенные важные источники (до 5) с измеренными CO2-данными для PEI/UiO-66 или влажного
   CO2 на UiO-66/UiO-66-NH2; проверить их DOI так же.

## Артефакт

`reviews/T004_registry_check.md` (русский): таблица `source_id | DOI ok | метаданные ok | указатель
на данные ok | лицензия ok | замечание`; список ошибок с исправлениями; пропущенные источники;
итог — какие записи можно использовать как `calibration`/`validation`.
