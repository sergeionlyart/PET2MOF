## Цель

Составить реестр первичных источников с **измеренными** данными, пригодными для вычислительной
оценки рабочей ёмкости CO2 композитов PEI/UiO-66 из влажного газа (5 % CO2/N2, 35 °C, 1 бар,
RH 0/40/70 %), и определить, каких данных нет.

## Что искать (расширять по научной необходимости)

1. Проверить, что S1–S3 разрешаются и что в них действительно есть (не верить описанию поручения):
   - S1 https://ug.edu.pl/news/pl/10481/innowacyjna-technologia-wychwytu-co2-grant-dla-wydzialu-chemii
   - S2 DOI 10.1021/acsomega.8b02319 (PMC6648867) — PEI@UiO-66-NH2
   - S3 DOI 10.1039/D5SU00463B — PET-derived UiO-66 (водный синтез)
2. CO2 (и по возможности N2, H2O) изотермы/ёмкости для: UiO-66 (в т.ч. дефектный, разные модуляторы),
   UiO-66-NH2, PEI-модифицированные UiO-66 и UiO-66-NH2 (импрегнация, разная загрузка), UiO-66 из ПЭТ.
3. Особенно: данные во **влажном** газе (RH>0, совместная адсорбция H2O/CO2, breakthrough с влажностью),
   изотермы воды на UiO-66/UiO-66-NH2, теплоты адсорбции, кинетика поглощения для PEI-композитов.
4. Аналоги для переноса закономерностей амин-эффективности во влажном газе (PEI на SiO2/других
   носителях с измеренными сухими и влажными ёмкостями при ~0.05–0.15 бар CO2) — помечать `analog`.
5. Проверка новизны: работы, где уже обсуждается немонотонное влияние загрузки PEI, блокирование пор,
   и/или влияние влажности на PEI-MOF композиты.

## Правила

* Каждый DOI проверять через `https://api.crossref.org/works/<DOI>` (заголовок, авторы, год, журнал).
  Непроверенные записи помечать `doi_verified: false`. Не выдумывать DOI, авторов, числа.
* Для каждого источника указать **где именно** данные (Table N / Fig. N панель / SI файл), тип данных
  (`table_numeric` | `figure_only` | `author_fit` | `simulation` | `text_value`), условия (T, p или p_CO2,
  RH, состав газа, загрузка PEI мас.% и как определена, Mw PEI, активация), нормировку ёмкости
  (на массу композита / MOF / на амин), лицензию (CC BY, CC BY-NC, closed) и OA-доступность.
* Не переписывать числа «по памяти». Если число взято из открытого текста/таблицы — указать точное место;
  оцифровка рисунков НЕ входит в эту задачу.
* Открытые полные тексты (только OA, законно доступные) можно скачать в `data/raw/html/` или
  `data/raw/pdf/` с записью URL, даты, SHA-256 в `sources/downloads_manifest.csv`.

## Ожидаемые артефакты

1. `sources/registry.yaml` — список записей с полями: `source_id` (S1, S2, … затем S100+ для новых),
   `doi`, `doi_verified`, `url`, `oa_url`, `title`, `authors` (первые 3 + et al.), `year`, `journal`,
   `license`, `accessed` (2026-11-16), `files_available`, `materials` (список), `conditions`,
   `data_items` (список: `{what, where, data_type, conditions, normalization}`), `role_candidate`
   (`calibration` | `validation` | `analog` | `context` | `novelty_check`), `limitations`.
2. `sources/audit_report.md` (русский язык): какие серии пригодны для калибровки, какие — для
   независимой проверки (целыми сериями), каких данных нет (особенно влажные данные для PEI@UiO-66),
   что подтвердилось/не подтвердилось в S1–S3, предшествующие работы по немонотонности PEI.
3. `sources/downloads_manifest.csv` — если что-то скачано.

## Критерии приёмки

* ≥ 12 источников с проверенными DOI, из них ≥ 6 с измеренными CO2-данными по UiO-66-семейству.
* Каждый `data_items` указывает конкретную таблицу/рисунок.
* Явный раздел «Отсутствующие данные».
* В финальном сообщении: список созданных файлов, число записей, главные пробелы.
