Задачи:

1. **Паспорта R0, R1, R2** (по одной короткой таблице): функциональные группы носителя и модификатора;
   предполагаемые связи (координация, водородные связи, иминная связь Шиффа через глутаровый альдегид, сшивка
   PEI–PEI, самоолигомеризация GA, физическое удержание); методы, которые их **количественно** подтверждают
   (элементный N, ЯМР растворённого образца, ТГА, XPS — с оговорками; FTIR — только качественно); конкурирующие
   механизмы; пути потери доступных аминов (потребление аминов альдегидом, блокировка, карбаматная «защита» CO₂ в
   методике C S2). Для R0 указать различие носителей SRC-03 (PET vs BDC — одна лаборатория) и отсутствие NH₂.
   Для R1 — что в обычном UiO-66 нет NH₂ линкера и что «закрепление» по S2 к нему неприменимо в исходном виде.
   Для R2 — что доля NH₂-BDC в каркасе ≠ доле в загрузке (SRC-06 Table S3) и что контроль — тот же смешанный
   каркас без PEI.
2. **Геометрическая доступность NH₂**: размеры окон/полостей UiO-66 по первоисточнику (структурная работа,
   DOI + локатор), размер PEI Mw 600 (если есть первоисточник; иначе `unknown` с диапазоном и обоснованием).
   Вывести формулу доли линкеров у внешней поверхности кристалла через размер кристалла (геометрия, без чисел
   из памяти); указать, есть ли в SRC-03/SRC-06 размер кристаллов (локатор) — иначе `unknown`.
3. **Пределы η** (дополнительная равновесная сухая сорбция CO₂ на моль N PEI при ≈298 K, ≈1 bar чистого CO₂)
   в `data/task003/eta_bounds_T041.csv`: `bound_id, quantity, value_or_range, unit, origin_class
   (stoichiometric_ceiling | literature_analog_measured | source_reported | project_scenario), mechanism,
   conditions, source_doi, locator, accessed, note`. Обязательно: стехиометрический потолок сухого карбамата
   (первичные/вторичные амины; третичные в сухом CO₂) с первоисточником; распределение аминов PEI S2 по его
   паспорту (S2 §4.1: общее содержание аминогрупп 32.9 мас.%, первичных 12.8 мас.% — **проверить, в каких
   единицах выражено**, и перевести в ммоль/г только с явным допущением); измеренные η в сухих PEI-сорбентах при
   условиях, близких к 298 K/1 bar, из открытых первоисточников (не менее двух независимых; таблица/рисунок).
   Стехиометрический потолок не выдавать за ожидаемое значение. Не придумывать чисел: недоступное — `unknown`.
4. **Массовый баланс глутарового альдегида**: остаток GA после двух иминных связей (стехиометрия), сколько аминов
   может потребить одна молекула GA; сведения об олигомеризации GA в воде (первоисточник). Сопоставить с массовым
   балансом S2: `W` (прирост массы на 1 г MOF), N элементный, PEI по формуле авторов (воспроизвести её из текста
   и Table 1 — формула в JATS дана изображением, проверить на числах Table 1). Записать, какая доля массы
   композита C72/N72/C96/I96 не объясняется ни MOF, ни PEI, и какие объяснения этому возможны (не выбирать одно
   без данных).
5. `reports/task003/drafts/route_compatibility_T041.md` (рус., ≤ 4 стр.): паспорта, выводы о совместимости каждого
   маршрута, что подтверждено для ПЭТ, что является аналогом; `reviews/T041_report.md` — источники и попытки доступа.

Критерии приёмки: каждое утверждение о химии или числе — с DOI и локатором прочитанного источника; разделены
измерения / оценки авторов / стехиометрия / проектные сценарии; нет переноса фотокаталитических выводов SRC-06 на
CO₂; нет утверждения о ковалентной связи PEI с каркасом без количественного подтверждения. Ничего не закоммичено.
