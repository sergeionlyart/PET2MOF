## Объём (D-08: только равновесная M1 + сценарный множитель конечного времени)

1. `src/pet2mof/model/` — модули:
   * `gas.py`: влажные мольные доли и парциальные давления (уравнение (1) спецификации), p_sat по IAPWS SR1-86
     (коэффициенты — из официального документа; в docstring — ссылка и проверочные значения из документа).
   * `isotherms.py`: Langmuir/DSL с T-зависимостью (2–3); аналитический IAST для Langmuir/DSL CO2/N2 (4–5),
     численное решение с проверкой; ступень воды Hill (7).
   * `pores.py`: объёмный баланс (6), (8)–(10) с проверкой допустимости (несовместимые наборы — флаг, не clip).
   * `amines.py`: (11)–(13) с непересекающимися пулами, `ν_d=min(0.5,f1+f2)`, ограничение `q_b ≤ q_W,P`.
   * `cycle.py`: квазиравновесный цикл (15) для R1/R2 с переносом остатков до периодического состояния и
     множителем `1−exp(−t/τ)` для химического пула (`τ/t ∈ {0,0.1,1,10}`); селективность; энергия (16–18)
     только символически/при заданных конечных параметрах.
   * `baseline.py`: B1 (19) и B0.
2. `src/pet2mof/calibration/`: подгонка носителя (CO2/N2 C-PHYS; пока T011 не завершён — по
   `provisional` NIST-сериям `10.1021/acs.inorgchem.5b00435` и `10.1039/C2cp23839j` **только как отладка**;
   итоговая подгонка — по `data/processed/c_series/` после T011v), подгонка PEI-вклада M1 и B1 на S100
   Fig. S5 (298 K; давление — абсолютное, D-15) при **двух** прочтениях загрузки `w=label/100` и `w=r/(1+r)`
   (D-10); профили правдоподобия для неидентифицируемых комбинаций; AICc; веса из погрешности оцифровки
   (`q_err` / межисполнительское расхождение) и протокольного допуска.
3. **Контрольное воспроизведение (этап 1):** воспроизвести S100 Fig. S5 моделями M1 и B1; проверить единицы,
   нормировки, балансы (объём, азот), предельные случаи (w=0 ⇒ носитель; RH=0 ⇒ нет воды; τ=0 ⇒ равновесие),
   численную сходимость (IAST, периодичность цикла). Отклонения сохранить. Паспорт запуска через `scripts/run.py`.
4. **Скрининг (debug, D-07):** `scripts/screen.py` — широкие стресс-границы всех неизвестных параметров уровня 2
   (влажная химия, вода PEI, τ, теплоты), чувствительность вердиктов H1/H1a (знаки Δ, w*, ранги) по ветвям
   механизмов; глобальная чувствительность (например, ранговая корреляция/Sobol на малом ансамбле). Паспорт
   `status: debug`. Итог — список параметров, от которых зависит вердикт, в `reviews/T013_screening.md`.
5. `configs/` — YAML со всеми параметрами: значение/диапазон, единицы, тип, source_id/extraction_id; загрузчик
   отказывает при числе без происхождения.
6. `scripts/validate.py` — **каркас** проверки V (S2 по D-11, S113/S103 носитель, S106/ie202325p вода) с
   метриками и допусками протокола; он **не должен содержать V-чисел** и читает V-данные из `holdout/`-путей,
   которых сейчас нет (без данных — понятная ошибка).
7. `tests/test_model_*.py`: единицы, балансы, предельные случаи, IAST против численного решения, B0-сокращение,
   отказ на числе без происхождения, детерминизм seed.
8. `make reproduce-demo` — быстрый контрольный пример (S100 Fig. S5 fit + один сценарий цикла) с ожидаемыми
   значениями и допусками в `configs/demo_expected.yaml`; время < 2 мин.

Отчёт: `reviews/T013_implementation_report.md` — что реализовано, результаты контрольного воспроизведения
(RMSE/MAE против допусков), предельные случаи, известные ограничения.
