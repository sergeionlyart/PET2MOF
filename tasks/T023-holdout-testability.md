Вход: `reviews/T019v2_holdout_reverification.md` (вердикты одной колонкой), `docs/holdout_schema.md`, правила **D-18**
в `docs/decisions.md`, паспорта `data/extraction/records/T019-*`, первоисточники в `data/raw/pdf/`.

1. Для каждой из 20 серий `holdout/v1/conditions.csv` — две независимые колонки:
   **A. извлечение** (числа/маркеры/единицы/основа сверены с источником: да / нет / не завершено — причина) и
   **B. условия** (достаточно ли известных входов для назначенного сравнения по D-18: полное / условное / нет — какого входа не хватает).
   Источник оценок A — отчёт T019v2 и его `T019v2-control/`; собственную повторную оцифровку не делать.
2. Для серий, где B = «нет» только из-за RH: прочитать методику первоисточника (основной текст и SI) и выписать
   **дословные** утверждения (≤ 2 фразы, с номером страницы) о сушке/активации образца, чистоте и сухости газа,
   способе измерения (объёмный/гравиметрический, чистый газ из баллона). Классифицировать: «сухость газа/образца прямо
   установлена источником» / «не установлена». Умолчания, «обычная практика», активация сама по себе — **не**
   доказательство сухости. Не выводить RH из тенденций данных.
3. Только чтение (без модели, без сравнения с прогнозами): загрузить `holdout/v1/observations.csv` штатным парсером
   `scripts/validate.py`/`src/pet2mof/...` (как это делает validate), включая строки с пустым q; сообщить, проходит ли разбор.
   Численные значения не печатать.

Выход: `reviews/T023_holdout_testability.md` — таблица `серия | A | B | недостающий вход | цитаты по сухости (стр.)`,
и итог: какие серии допускают полное, условное сравнение или ни одного по уже действующим правилам D-18.
