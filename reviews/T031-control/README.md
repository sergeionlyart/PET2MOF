# T031-control — фрагменты таблиц S2

`tbl1.xml` и `tbl2.xml` — только Table 1 и Table 2 (с подписями и примечаниями) из открытого JATS статьи S2, полученного
17.11.2026 через Europe PMC API (`https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6648867/fullTextXML`).
Полный текст статьи в репозиторий не включён. SHA-256 — `SHA256SUMS.txt`.

Frameworks: Preparation and Enhanced CO2 Selective Adsorption*. ACS Omega 2019, 4, 3188–3197,
DOI 10.1021/acsomega.8b02319. Статья распространяется издателем по ACS AuthorChoice с разрешением копирования и

некоммерческом исследовательском репозитории. Лицензия кода проекта на эти фрагменты не распространяется; для
коммерческого использования проверьте условия издателя.
