## Учитываемый запуск после коммита руководителя

Ниже команды для bash из корня чистого checkout после фиксации кода и отладочных отчётов.
Сам исполнитель commit не создавал, индекс не менял. Для обычной отладки достаточно двух make-целей;
они явно оставляют run_id `debug-unregistered`. Для учитываемого запуска не использовать `--allow-dirty`.

```bash
export UV_CACHE_DIR="$PWD/.uv-cache"
export UV_PYTHON_DOWNLOADS=never

git status --porcelain --untracked-files=all
# Продолжить только при пустом выводе.

pack=data/task002/PET2MOF_Task002_DataPack_v1.0
input_args=()
while IFS= read -r path; do
  input_args+=(--input "$path")
done < <(git ls-files -- "$pack")

output_args=()
for path in \
  reports/task002/intake/acceptance.json \
  reports/task002/A/nominal.csv \
  reports/task002/A/stress_independent.csv \
  reports/task002/A/stress_common_factor.csv \
  reports/task002/A/pairwise.csv \
  reports/task002/A/candidates.csv \
  reports/task002/A/candidates.md \
  reports/task002/A/reproduce_reference.json \
  reports/task002/A/provenance.json; do
  output_args+=(--output "$path")
done

uv run --locked --no-sync python scripts/run.py \
  --name task002-A \
  --purpose 'Приёмка пакета и сухое сравнение S2, T030' \
  --hypothesis 'Сухая q определяет кандидатов; различимость проверяется ограниченными сценариями' \
  "${input_args[@]}" "${output_args[@]}" \
  -- .venv/bin/python scripts/task002/reproduce.py --run-id '{run_id}'
```

`scripts/run.py` фиксирует commit, версии среды, SHA-256 всех входов/выходов, команду, exit code и ресурсы
в `runs/<run_id>/passport.json`. Вложенные скрипты используют тот же интерпретатор и получают тот же run_id.
Фиксированные параметры анализа находятся в хешируемом `metadata/analysis_contract.json` и чистом коде;
случайные числа и подгонка отсутствуют. Проверить `status=completed`, `exit_code=0`,
`acceptance.status=passed`, `reproduce_reference.passed=true`. Повторять учитываемый запуск следует
из чистого checkout: предыдущая запись отчётов меняет отслеживаемые файлы.
